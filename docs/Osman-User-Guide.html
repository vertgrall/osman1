Osman User Guide

See your network breathe — Phase 1 · New Tower · macOS 14+

Osman is a native Mac network monitor. It shows live adapter traffic, processes, connections, traffic patterns, and alerts — from the menu bar or a full window. No root access. No packet capture.

Analogy — dashboard vs. security camera
Think of Osman like a building utility meter plus a front-desk sign-in sheet. The hero chart is total water flow; each adapter is a pipe; connections are who walked through the door and when.

3 · Reading the Overview

  • Receive (green lane) — bytes coming in
  • Send (orange lane) — bytes going out
  • Total — combined rate
  • Peak in the header — highest total rate in the visible window
Tip: Click any adapter row to open the bottom detail panel — statistics, activity chart, top talkers.

4 · Menu bar mini monitor

Enable Menubar only in Settings → General to hide the Dock icon and run from the tray.

5 · Alerts & presets

Osman watches traffic every poll (default 1 second) and can notify you when rules fire.

Built-in rules

RuleWhat it catches
Total bandwidth spikeCombined traffic above threshold for N seconds
Adapter heavy loadOne interface saturated
New outbound public connectionProcess talks to a non-private IP for the first time
Wildcard listenerProcess listening on *:port
Connection fan-out spikeMany new connections in one poll

Alert presets (one-click plays)

PresetBest for
BalancedEveryday use — default mix
Security WatchCatch new public connections & listeners
Quiet MonitorOnly wildcard + fan-out alerts
DeveloperDocker/npm — fewer false positives
Metered / HotspotLow bandwidth ceilings on cellular
Heavy DownloadLarge transfers OK — extreme spikes only

Tap a preset card to apply. Manual ± tweaks switch the profile to Custom. Click a rule row to toggle On/Off.

8 · Themes

Nine light themes tune receive / send / total waveform colors and surface tint. Settings → General → pick a swatch row. Favorites:

  • Clinical Sage — default calm monitor
  • Cardinal Scope — red accent
  • Pine Monitor — dark green accent
  • Solar Scope — golden yellow accent
  • Primary Signal — traffic-light lanes
